# Krishna Koushitha P — Portfolio Website

A responsive, single-page portfolio built with HTML, CSS, and JavaScript. No build tools or installation are required.

## Files
- `index.html` — page content and project links
- `style.css` — layout, responsive styles, colors, and typography
- `script.js` — mobile navigation and current year

## Run it locally
1. Extract the ZIP file.
2. Open the `koushitha_portfolio` folder.
3. Double-click `index.html` to open it in your browser.

You can also open the folder in VS Code and use the Live Server extension.

## Personalize before publishing
1. In `index.html`, replace `YOUR_EMAIL@example.com` with your real professional email in both the `mailto:` link and visible text.
2. Check all LinkedIn, GitHub, and project links.
3. Keep only skills you can confidently discuss in an interview.
4. The Sales Analytics Dashboard card is a concept preview, not a connected Power BI report. Build your own dashboard and replace the sample-data link with your published report or project repository.
5. Review project descriptions so they accurately reflect what you built and your contribution.
6. Add a resume link if you want recruiters to download your latest resume.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new public repository named `koushitha-portfolio` (or another name).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. Your URL will be shown in the Pages settings.

## Share on LinkedIn
After publishing, create a LinkedIn post with the live URL. Explain what you built, list the technologies used, and invite feedback. Do not share the local `index.html` file path as a live website link.
